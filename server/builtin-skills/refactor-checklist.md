## 解决方案
1. 建基线：先跑测试套件确认全绿（`npm test`），作为「行为不变」的对照。
2. 小步快跑，每步单一意图：
   - 重命名/提取函数/拆大类 → 用 IDE 重构工具而非手动全局替换，避免漏改。
   - 抽公共逻辑前先确认调用方语义一致（参数顺序、边界、异常）。
   - 删死代码前 `grep` 确认无引用。
3. 每改一步立刻跑相关测试；红了立刻停手定位，不让「半成品」堆积。
4. 保持对外行为不变：公开 API 签名、返回结构、副作用边界不悄改；确需改时同步更新调用方与文档。
5. 收尾给对比：可读性/复用/性能改进点，以及「为什么这样更好」。

## 验证
`npm test` 全绿（与基线一致）；`git diff` 仅含重构、无行为变更；lint 无新增告警。
